# Learning Resources for My Personal Blog

This document provides a list of resources to help you understand and contribute to my personal blog built with **Next.js**.

## 📚 Topics Covered
- **Next.js** – Learn how to build and optimize React applications.
- **React** – Understanding React concepts and best practices.
- **Tailwind CSS** – Styling with utility-first CSS framework.
- **MDX** – Writing articles using Markdown and React components.
- **MongoDB** – Database management for the blog.

## 🔗 Useful Links
- [Next.js Documentation](https://nextjs.org/docs)
- [React Documentation](https://react.dev/)
- [Tailwind CSS Guide](https://tailwindcss.com/docs)
- [MDX Documentation](https://mdxjs.com/docs/)
- [MongoDB Documentation](https://www.mongodb.com/docs/)

## 🎯 Learning Path
1. Start with the basics of **React**.
2. Learn how **Next.js** enhances React for better performance.
3. Get comfortable with **Tailwind CSS** for styling.
4. Understand how **MDX** works for writing blog posts.
5. Master **MongoDB** for managing data efficiently.

Happy learning! 🚀
